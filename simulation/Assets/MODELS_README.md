# Models Folder (Not Tracked in Git)

This folder is excluded from version control because it contains large third-party Unity Asset Store models (over 1 GB total).

## To set up the project, re-import these assets:

- **Apocalyptic City Pack** - Unity Asset Store
- **Dystopian Stairway** - Sketchfab / Unity Asset Store  
- Additional textured .obj models

Place all imported model files inside `Assets/MODELS/` after cloning the repo.
